# SpeakLocal

Native macOS TTS app using **Kokoro-82M** on Apple Silicon.

## On your Mac Studio — run this in Terminal

```bash
git clone https://github.com/dudutaulois/SpeakLocal.git ~/Desktop/SpeakLocal
cd ~/Desktop/SpeakLocal
chmod +x install.sh setup-and-open.command
./install.sh
open Package.swift
```

Then press **⌘R** in Xcode.

**Your project path:** `~/Desktop/SpeakLocal`

## Or double-click

After cloning, double-click `setup-and-open.command` in Finder.

## Requirements

- Apple Silicon Mac (M1+)
- macOS 14+
- Xcode 15+
- Python 3.10–3.12 (`brew install python@3.12`)
